# RPG Maker MV JavaScript Plugins

RPG Maker MV에서 사용할 수 있는 JavaScript 플러그인을 개발하고 관리하는 저장소입니다.

게임 개발 과정에서 제작한 플러그인을 정리하고, JavaScript와 RPG Maker MV의 내부 구조를 학습하기 위한 개인 프로젝트입니다.

## 📖 Repository Overview

이 저장소는 RPG Maker MV의 기본 기능을 확장하거나 새로운 게임 시스템을 구현하기 위한 JavaScript 플러그인을 관리합니다.

주요 목적은 다음과 같습니다.

- RPG Maker MV 플러그인 개발
- JavaScript 프로그래밍 학습
- 게임 시스템 구현 및 실험
- 프로젝트에서 재사용 가능한 기능 관리
- 개발 과정 및 학습 기록 보관

플러그인은 지속적으로 추가 및 개선될 예정입니다.

# RPG Maker MV JavaScript Plugins

A collection of JavaScript plugins developed for RPG Maker MV.

This repository contains custom plugins created while learning JavaScript and exploring the internal architecture of RPG Maker MV through practical game development.

## 📖 Repository Overview

The purpose of this repository is to develop and maintain reusable JavaScript plugins for RPG Maker MV.

Main objectives include:

- Developing custom RPG Maker MV plugins
- Learning JavaScript through practical projects
- Implementing and extending game systems
- Managing reusable components
- Documenting the development and learning process

New plugins and improvements will be added as development continues.
